These are the datasets that the different AI agents will read to create the timeline of events according to their personalities.

More precisely, there are stock market tweets 
- (https://www.kaggle.com/datasets/dawoodaijaz/stock-market-tweets-labelled-with-gcp-nlp)

Disaster tweets were collected on Jan 14th, 2020 
- (https://www.kaggle.com/datasets/vstepanenko/disaster-tweets)

Covid 19 tweets
- (https://www.kaggle.com/datasets/arunavakrchakraborty/covid19-twitter-dataset)

And lastly, to add a little bit of variance into the thinking of the agents, tweets of a well-known Asian game developer, Hideo Kojima.
- (https://www.kaggle.com/datasets/luciesteel/kojima-tweets-en).

There are two different versions of each dataset: the first is the original version, while the versions with "_final" in their names have undergone some processing, retaining the same column names and removing non-essential information for this project.
